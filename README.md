User Authentication Practice Project

A beginner-friendly backend authentication project built using
Node.js, Express.js, MongoDB, and EJS. 
This project was created to practice user registration, login, password hashing, JWT token generation, and cookie-based logout.

Features
User registration with username, email, password, and age
Duplicate email checking
Password hashing using bcrypt
Login with email and password
Password verification using bcrypt.compare()
JWT token generation after registration and login
Cookie-based token storage
Logout functionality using cookie clearing
EJS templates for Home, Register, and Login pages
MongoDB database integration using Mongoose
Created and updated timestamps for user documents

Tech Stack
Runtime: Node.js
Backend: Express.js
Database: MongoDB
ODM: Mongoose
Templating Engine: EJS
Password Hashing: bcrypt
Authentication: JSON Web Token (JWT)
Cookie Handling: cookie-parser
Environment Variables: dotenv
